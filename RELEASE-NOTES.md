# ProGlide 1.4 — transparent front-view polish

- Removed the top-down movie and its solid image background.
- Uses transparent front-camera renders of Apple's original AirPods Pro 3 USDZ model. The model geometry is original; camera, lighting and hinge animation are app-authored. This is not an untouched Apple animation.
- Stable product alignment and subtle edge shadow work in both Light and Dark themes.
- Preferences is shorter, with expandable name matching and a combined About/Save footer.
- Dedicated Left, Right and Case battery cards are always visible. Missing values show a dash and an explanation; disabled/unavailable scanning states are clear.
- Partial battery packets preserve recent components from the same advertiser, with 60-second expiry and per-component age/charging labels. Broadcast ownership remains unverified.
- The app remains a compact single executable using the .NET Framework built into Windows 11. No renderer, model-processing tool or bundled runtime is installed with it.

See ARTWORK-PROVENANCE.md for the model URL, hash and rendering details. Test reports record local verification; a clean second PC was not available.
